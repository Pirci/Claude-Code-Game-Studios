## Kurulum

| Platform | Dosya | Açma |
|---|---|---|
| macOS | `ULUS.zip` → `ULUS.app` | İlk açılışta **sağ tık → Aç** (notarize edilmedi). Olmazsa: Sistem Ayarları → Gizlilik ve Güvenlik → "Yine de Aç" |
| Windows | `ULUS-windows.zip` → `ULUS/ULUS.exe` | SmartScreen çıkarsa **Ek bilgi → Yine de çalıştır** |

Kayıt/ayar klasörü (temiz başlangıç için silinebilir):
macOS `~/Library/Application Support/Godot/app_userdata/ULUS/` ·
Windows `%APPDATA%\Godot\app_userdata\ULUS\`

## Oturum planı (~30–40 dk)

1. **İlk açılış (2 dk)** — pencere 1920×1080, pikseller keskin mi? Menü sistem dilinde mi?
2. **Kör oynanış (20–35 dk)** — Yeni Kampanya → intro → Prolog'u **ipuçlarından başka yardım
   almadan** bitirmeye çalış. Not al: nerede takıldın, neyi anlamadın, neresi keyifliydi.
   Hedef: Kağan ilanına (zafer → lütuf seçimi → outro) çökmeden ulaşmak.
3. **Kayıt / devam (3 dk)** — oyunun ortasında çık, yeniden aç → "Devam Et" aynı turdan
   sürüyor mu?
4. **Ayarlar (3 dk)** — dili değiştir (ör. Türkçe → Arapça → Türkçe), oyunu kapat-aç: dil
   korunuyor mu? Ses kaydırıcıları, tam ekran, renk körü modu.
5. **Kenar durumlar (isteğe bağlı)** — yenilgi (ordusuz bırak), Erlik gölgesinin büyümesi,
   pencereyi yeniden boyutlandırma, Tab/ok tuşlarıyla menü gezinmesi.
